Read these rankings correctly

Rank-1 is the fraction of queries whose first match has the right vehicle ID. mAP rewards placing all correct gallery images early in the ranked list. Parameters are active inference parameters. CPU latency is milliseconds per crop on the machine used for these CSVs; it is not Raspberry Pi AI Camera latency.
